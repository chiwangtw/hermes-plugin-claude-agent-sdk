# hermes-claude-agent-sdk

Standalone Hermes Agent model-provider plugin: run Hermes on a Claude Pro/Max
subscription through the official Claude Agent SDK.

Status: bootstrapping. See `docs/HANDOFF.md` for research findings and
`docs/PRD.md` (TODO) for scope.

Install target (once built):

```
~/.hermes/plugins/model-providers/claude-agent-sdk/
├── plugin.yaml
└── __init__.py
```
